# Context Decoder - 개발자 통합 도구 크롬 확장 프로그램

Base64 인코딩/디코딩, HTTP API 테스트, Mermaid 차트 시각화, 실시간 번역, 코인 선물 레버리지 계산기 등 다양한 개발자 도구를 제공하는 크롬 확장 프로그램입니다.

## 주요 기능

### 1. 📦 Base64 인코딩/디코딩
- **Base64 디코딩**: Base64 텍스트를 UTF-8로 변환
- **Base64 인코딩**: 일반 텍스트를 Base64로 변환
- **JWT 토큰 자동 파싱**: JWT 형식 자동 감지 및 헤더/페이로드 추출
- **이미지 자동 인식**: PNG, JPEG, GIF, WebP 이미지를 새 탭에서 표시
- **Data URL 지원**: `data:image/...;base64,...` 형식 자동 처리

#### 사용 방법
1. **단축키**: 텍스트 선택 후 `Alt+Shift+D`
2. **우클릭 메뉴**: 텍스트 선택 후 우클릭 → "선택한 텍스트 Base64 디코딩 (복사)"
3. **플러그인 팝업**: Base64 탭에서 텍스트 입력 → 디코드/인코드 버튼

### 2. 🌐 HTTP API 테스트
- **HTTP 메서드 지원**: GET, POST, PUT, DELETE, PATCH
- **커스텀 헤더**: JSON 형식으로 헤더 설정
- **요청 바디**: JSON 바디 전송
- **토큰 자동 추가**: 저장된 기본 토큰을 헤더에 자동 추가
- **응답 표시**: 상태 코드, 헤더, 바디를 상세하게 표시
- **기본값 설정**: 자주 사용하는 URL, 메서드, 헤더 저장

### 3. 📊 Mermaid 차트 시각화
- **다이어그램 타입 지원**: Flowchart, Sequence, Class, State, ER, Gantt, Pie 등 지원
- **클라이언트 사이드 렌더링**: 로컬에서 SVG 생성
- **오버레이 표시**: 현재 웹 페이지에 차트를 오버레이로 표시
- **예제 제공**: 다양한 다이어그램 예제
- **단축키**: 선택한 Mermaid 코드에서 `Alt+Q`로 오버레이 표시
- **SVG 다운로드**: 렌더링된 차트를 SVG 파일로 저장

### 4. 🗣️ 실시간 번역
- **무료 API 활용**: MyMemory API를 사용하여 별도 키 없이 번역 가능
- **언어 자동 감지**: 소스 언어를 자동으로 감지하여 한국어/영어 등으로 번역
- **단축키 지원**: 웹 페이지에서 텍스트 선택 후 `Alt+Shift+T`로 즉시 번역
- **팝업 번역**: 팝업 앱 내에서 텍스트를 직접 입력하여 번역 및 결과 복사

### 5. 💹 레버리지 계산기 (코인 선물용)
- **최적의 익절/손절가 계산**: 체결가, 레버리지, 손실율(%) 입력 시 TP/SL 가격 즉시 산출
- **다중 거래 항목 관리**: 여러 개의 거래 포지션을 리스트로 관리 (로컬 자동 저장)
- **클릭 시 복사**: 계산된 가격을 클릭하면 소수점까지 정확하게 클립보드에 복사
- **포지션 지원**: Long/Short 양방향 대응

### 6. 📝 메모 관리 (K-V 시스템)
- **키-값 저장**: 제목과 내용으로 메모 저장
- **로컬 저장**: Chrome Local Storage에 안전하게 저장
- **복사 기능**: 저장된 메모를 클립보드로 복사
- **삭제 기능**: 불필요한 메모 삭제
- **단축키**: `Alt+Shift+S`로 페이지 텍스트 메모, `Ctrl+S`로 팝업 내 폼 메모 저장

### 7. ⚙️ 설정 및 도움말
- **기본 설정 저장**: 기본 URL, 메서드, 헤더 및 복수 토큰 관리
- **도움말 힌트**: 각 탭별로 사용 가능한 단축키 가이드 표시
- **On/Off 토글**: 확장 기능을 팝업에서 즉시 활성화/비활성화

## 설치 방법

### Chrome / Brave / Edge
1. 이 저장소를 다운로드 또는 클론
2. `chrome://extensions/` 접속 (개발자 모드 활성화)
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 프로젝트 폴더 선택

## 사용 예시

### 1. Base64 텍스트 디코딩
`SGVsbG8gV29ybGQh` 선택 후 `Alt+Shift+D` → `Hello World!` 복사됨

### 2. 번역 기능
영어 텍스트 선택 후 `Alt+Shift+T` → 한국어 번역 결과 오버레이 표시

### 3. 레버리지 계산
입력: 65,000 (체결가), 10 (배수), 5 (손실율) → SL: 64,675 / TP: 65,325 산출

|------|--------|------|

## 기술 스택

- **Chrome Extension**: Manifest V3
- **언어**: Vanilla JavaScript (ES Modules)
- **라이브러리**: Mermaid.js (차트), MyMemory API (번역)
- **저장소**: Chrome Storage API (Local & Sync)

## EPUB Reader (로컬 전용)

기존 확장 프로그램 팝업의 **EPUB Reader ↗** 버튼을 누르면 전체 화면 리더 탭이 열립니다.
파일 선택 또는 드래그 앤 드롭으로 DRM이 없는 EPUB 파일을 읽을 수 있습니다.
목차, 이전/다음 페이지(버튼·방향키·마우스 휠), 글자 크기, 다크 모드, 마지막 읽던 위치 저장을 지원합니다.
마우스 휠은 한 번의 스크롤 동작(250ms 이상 멈춤으로 구분)당 한 페이지씩 넘깁니다. `Ctrl`+휠은 브라우저 확대/축소로 남겨둡니다.
책의 내용은 외부 서버에 업로드되지 않으며, epub.js의 스크립트 실행 허용 옵션은 꺼져 있습니다.

### 최초 1회 라이브러리 설치

```bash
npm install
npm run build:epub
```

이후 `chrome://extensions`에서 확장을 새로고침하거나 압축 해제된 확장을 다시 로드하세요.
EPUB 렌더링에 필요한 JSZip 3.10.2와 epub.js 0.3.93은 npm에서 설치한 뒤
`libs/` 디렉터리에 복사됩니다. 브라우저에서 CDN이나 원격 실행 코드를 가져오지 않습니다.
EPUB 렌더링 라이브러리 번들은 저장소에 포함하지 않으므로, 새로운 PC에서는 이 빌드 과정을 반복해야 합니다.
DRM이 적용된 파일은 지원하지 않습니다.

### 최근 책: 파일 핸들 방식

- **새 EPUB을 열 때** Chrome의 `showOpenFilePicker()`로 원본 파일을 선택하고 `FileSystemFileHandle`만 IndexedDB에 저장합니다. EPUB 파일 전체를 복제하지 않습니다.
- 최근 10권의 제목과 파일 참조를 보관하며, 리더 첫 화면 또는 상단 **최근 책**에서 바로 열 수 있습니다.
- 브라우저 재시작 등으로 접근 권한이 해제되면 다시 **읽기 권한**을 요청합니다. 원본 파일을 이동/삭제하면 해당 핸들로 열 수 없습니다.
- **이전 버전**에서 저장한 Blob 사본은 즉시 삭제하지 않고 `이전 저장본 · 클릭해 원본 연결`로 표시합니다. 동일한 이름의 원본 EPUB을 선택하면 저장된 Blob을 파일 핸들로 대체합니다. 이때 같은 책의 저장된 위치는 가능한 한 유지합니다.
- 로컬 EPUB을 드래그 앤 드롭했을 때 파일 핸들 API를 이용할 수 있다면 최근 책에 등록합니다. 지원되지 않는 경우 **현재 탭에서만 임시 열람**하며 EPUB 내용을 저장하지 않습니다.
- 새로운 EPUB 파일 내용을 IndexedDB에 저장하지 않으며, 이전에 저장된 사본은 원본 연결 또는 목록 삭제 시 제거됩니다.

### 보기 편한 최근 목록 정리

- 각 책 우측 **삭제** → 해당 책의 최근 목록·파일 핸들/기존 Blob·위치 인덱스·읽던 위치 제거 (확인 대화상자 표시)
- 목록 상단 **목록 전체 삭제** 또는 초기 화면 **전체 삭제** → 모든 EPUB 최근 목록·기존 Blob·위치 인덱스·읽던 위치 제거 (확인 대화상자 표시)
- 이 기능은 **디스크의 원본 EPUB을 삭제하지 않습니다.** 테마 및 글꼴 설정도 유지합니다.
- 브라우저에서 저장된 파일 접근 권한이 사라지거나 파일을 옮기면 EPUB 열기를 눌러 다시 추가하면 됩니다.

### 페이지 번호 이동

- 하단 **위치**에 숫자를 입력하고 Enter 또는 **이동**을 클릭해 해당 위치로 이동합니다.
- EPUB은 고정 페이지가 없어 원본 인쇄 페이지가 아닌 `book.locations.generate(1600)`의 전체 책 위치 인덱스를 사용합니다.
- 처음 열 때 계산하고 인덱스만 IndexedDB에 캐시합니다. 읽던 위치(CFI)와 글꼴·다크 모드 설정은 `chrome.storage.local`에 별도 저장합니다.
- 원본 EPUB이 수정되면 변경된 크기/수정 시각을 감지해 이전 위치 인덱스 및 읽던 위치를 초기화합니다.
- 저장 데이터는 이 Chrome 프로필과 확장 설치에 속합니다. 확장을 삭제하면 최근 목록도 사라집니다.

**주의:** EPUB 기능은 별도 사이트 접근 권한이 필요하지 않지만,
기존 확장 프로그램의 `<all_urls>` 권한과 전체 웹사이트용 콘텐츠 스크립트는 그대로 유지됩니다.
금융/코인 지갑과 함께 사용할 때는 Chrome 프로필 분리를 권장합니다.
